# 뉴욕 AI 워크숍 — 사전 설치 스크립트

워크숍 실습 도구를 한 번에 설치하는 스크립트입니다. Claude 앱에 안내 문장을 붙여 넣으면 Claude 가 이 스크립트를 받아 실행합니다.

| 파일 | 대상 | 하는 일 |
|---|---|---|
| `install-win.ps1` | Windows 10(1809+) · 11 | winget 으로 16가지 설치. 「예」(사용자 계정 컨트롤) 창 2번 |
| `install-mac.sh` | macOS 13+ | pixi 와 공식 설치 파일로 13가지 설치. 비밀번호 없음 |

- 설치만 합니다. 로그인 · 가입은 하지 않습니다.
- 이미 깔린 것은 건너뛰어서 몇 번을 다시 돌려도 안전합니다.
- 실패한 단계만 다시: `-Only <번호>`(윈도우) · `--only <번호>`(맥)
- 기록: `%USERPROFILE%\nyc-install.log` · `~/nyc-install.log`
